
## 分布式锁为什么用lua脚本而不是shell脚本

Lua 是 Redis 内置、服务器端可执行的脚本语言。

Redis 单线程只保证“单条命令”不会被并发打断，但**两条命令之间仍然会穿插其他客户端命令**。Lua 的意义是把“多条命令的组合逻辑”变成 Redis 的“一条命令”，从而获得组合操作的原子性/隔离性

Lua 脚本可以把 “校验 value + 删除” 合并到 Redis 内部一次执行Redis 会保证脚本执行期间不会插入其他命令，从而消除这个竞态窗口。

分布式锁用 Lua，是因为它能在 **Redis 服务器端**把“检查 + 修改”做成**一次不可被插队的原子操作**；shell 脚本只能在客户端跑，最终仍是多次 Redis 调用，既不原子也更不可靠。
