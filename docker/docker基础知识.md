
# docker 是什么---名词定义


Docker 是一个软件，其可以为**特定软件**创建出一个**轻量级的、自带所有运行依赖、且与宿主机共享内核和硬件资源**的**独立执行环境**。

这个独立的执行环境+特定软件在**运行状态时**就叫做**容器**。

可使用命令将**容器**打包成**可移植的**只读文件，这个只读文件叫做**镜像**。


## docker因为其功能所带来的特点

- **软环境完整封装：** Docker 镜像包含了程序运行所需的一切：特定的二进制文件、特定版本的库文件（.so 或 .dll）、配置文件、环境变量等。
    
- **同其余软件解除对同一前置依赖的依赖：** 如果 A 应用需要 Python 2.7，而但是B 应用需要 Python 3.10，在宿主机上直接安装可能会版本冲突。但在 Docker 中，它们各自住在自己的容器里，互不干扰。
    
- **不可变性：** 镜像一旦构建完成就是只读的，换一个宿主机来运行里面的依赖库版本也不会发生改变
