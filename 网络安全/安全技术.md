# SSH隧道




# 非对称加密算法

## ed25519

### 1、常见使用方法 Linux 中使用命令
```bash
ssh-keygen -t ed25519
```

|命令片段|含义与作用|
|---|---|
|`ssh-keygen`|核心命令，是 OpenSSH 提供的密钥生成工具，用于创建、管理和转换 SSH 认证密钥。|
|`-t`|`type` 的缩写，是指定密钥类型的参数，必须后跟具体的算法名称。|
|`ed25519`|密钥算法类型，基于 Edwards-curve Digital Signature Algorithm（EdDSA），使用 Curve25519 椭圆曲线，特点是：<br><br>- 安全性极高（等效于 RSA 4096 位）<br><br>- 密钥长度短（仅 256 位）<br><br>- 生成 / 验证速度快|

### 2. 完整命令执行流程（新手友好版）

执行 `ssh-keygen -t ed25519` 后，终端会依次提示你：

bash

运行

```
# 执行命令
$ ssh-keygen -t ed25519

# 第一步：指定密钥保存路径（默认 ~/.ssh/id_ed25519，直接回车用默认路径即可）
Generating public/private ed25519 key pair.
Enter file in which to save the key (/home/你的用户名/.ssh/id_ed25519): 

# 第二步：设置私钥密码（可选，建议设置，增强安全性；直接回车则无密码）
Enter passphrase (empty for no passphrase): 

# 第三步：确认私钥密码（如果第二步设置了密码，需要重复输入）
Enter same passphrase again: 

# 生成成功的提示
Your identification has been saved in /home/你的用户名/.ssh/id_ed25519
Your public key has been saved in /home/你的用户名/.ssh/id_ed25519.pub
```

### 3. 生成的文件说明

执行成功后，会在 `~/.ssh/` 目录下生成两个文件：

- `id_ed25519`：**私钥文件**（核心，必须妥善保管，不能泄露给任何人），权限需设置为 `600`（`chmod 600 ~/.ssh/id_ed25519`），否则 SSH 会拒绝使用。
- `id_ed25519.pub`：**公钥文件**（可公开），需要将其内容复制到你要登录的远程服务器的 `~/.ssh/authorized_keys` 文件中，才能实现免密码登录。

### 4. 常用扩展参数（可选）

如果需要自定义密钥名称或添加注释，可补充参数：

bash

运行

```
# -C 添加注释（通常是邮箱，方便识别密钥归属）
# -f 指定密钥保存路径/名称（避免覆盖默认密钥）
ssh-keygen -t ed25519 -C "your_email@example.com" -f ~/.ssh/my_ed25519_key
```

### 总结

1. `ssh-keygen -t ed25519` 的核心作用是生成安全的 ED25519 类型 SSH 密钥对，用于 SSH 免密码认证。
2. 生成的私钥（`id_ed25519`）需保密且设置 `600` 权限，公钥（`id_ed25519.pub`）需配置到远程服务器的 `authorized_keys` 中。
3. ED25519 算法相比传统 RSA 更安全、高效，是目前 SSH 密钥的首选。
